---
description: Google Analytics overview for a property and period
argument-hint: "[property or site name] [period, e.g. last 28 days]"
---

Using the google-analytics MCP tools, produce an overview for: $ARGUMENTS

If no property is given, use `list_accounts` and ask which one. Default period: last 28 days compared with the previous 28 days.

Include: users, new users, sessions, engagement rate, key events and revenue (if any); top 10 channels, top 10 landing pages, top countries and device split; then 3–5 notable changes or insights.
